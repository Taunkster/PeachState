# dashboard/ — PeachState CoolChain Streamlit command center (Day 5 complete)

```bash
.venv/bin/python -m streamlit run dashboard/app.py
```

Default is **FIXTURES mode**: the app reads SQLite + JSON only (`data/fixtures/dashboard/*`)
and makes zero API calls — fully offline-safe. Sidebar toggles FIXTURES | LIVE | HYBRID
(LIVE/HYBRID degrade gracefully to fixtures when the network or `FG_API_KEY` is absent).

## Layout

```
dashboard/
├── app.py                    # entry point, sidebar, 6-tab router, session state
├── data_source.py            # FIXTURES/LIVE/HYBRID seam + @st.cache_data loaders
├── fixtures_gen.py           # deterministic offline fixture generator (shared)
├── components/
│   ├── field_map.py          # GA farm polygons + heat-tile time slider (08-17 EDT)
│   ├── corridor_map.py       # I-75 vs I-16 dual route + temp profile + summary cards
│   ├── risk_charts.py        # 24h risk series, harvest windows, spoilage curve, radar
│   ├── harvest_alerts.py     # active alert table + SMS preview + packing house + ack
│   ├── cold_chain_kpis.py    # 23% / $180K / 12% / 96% cards + sparklines + drill-down
│   └── hi_report.py          # embedded PDF viewer + download + synthetic fallback
└── styles/
    └── theme.py              # GA flag palette, 7-stop heat gradient, Inter/Mono CSS
```

## Tabs

Field Map · Corridor Map · Risk Charts · Harvest Alerts · KPI Dashboard · HI Report

## Data

- `data/ga_fields.geojson` — 45 farms (peach/pecan/blueberry/onion), risk tiers colored
  green/yellow/orange/red, clicking a farm populates the sidebar detail panel.
- `data/corridor_nodes.json` — I-75 (318 mi) vs I-16 (176 mi) Macon → Port of Savannah.
- `data/fixtures/dashboard/*.json` — generated by
  `scripts/gen_dashboard_fixtures.py` (also seeds the SQLite store).
- `data/fixtures/heat_intelligence_fort_valley.pdf` — Day-2 live Premium HI report.
